# ROMTech Order Center

A NetSuite-style sales order app built with React, Next.js and TypeScript.

## Run it

    git clone https://github.com/ivanjohnalcaide/romtech-order-center.git
    cd romtech-order-center
    npm install
    npm run dev

Open http://localhost:3000

## Production build (optional)

    npm run build
    npm start

## Stack

- **React**: components in `components/`
- **Next.js**: pages, Server Action and API route in `app/`
- **TypeScript**: types in `lib/types.ts`
